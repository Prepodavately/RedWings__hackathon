## Запуск в PowerShell
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:USE_MOCKS="0"
.\.venv\Scripts\python.exe -m streamlit run app.py
```
По умолчанию включены модули команды (0). Демо включается только явно (1).
Таблицы пересобираются при изменении исходных файлов или кода парсеров.
Для подложки карты нужен доступ браузера к CDN Plotly.

## Возможности
- Обе стратегии и два сценария; выбор хаба из актуального топ-3 для нового хаба.
- Количество маршрутов берётся из видимых сетей (сейчас по 10 уникальных пар).
  Несовпадение сетей блокирует расчёт, а не маскируется обрезкой таблиц.
- Географическая карта всех 12 кандидатов и маршрутов; топ-3 выделен.
- Паспорт каждой пары: доказательство спроса, частоты, тарифы, источники,
  ж/д альтернатива, субсидии, существующие рейсы RW.
- Геометрический крюк через Москву; время стыковки не выдумывается.
- Проверка устойчивости топ-3 на 2000 наборах весов (seed 42).
- Кривая эластичности тарифа Dev 3 как отдельный эксперимент.
- Тепловая карта 117 комбинаций и стресс-тест загрузки до безубыточности.
- Аудит данных, экспорт таблиц, предложенные кварталы запуска.
- Единый светлый дизайн: тёмно-синий заголовок, карточки показателей,
  красный цвет хаба и синий P2P, компактные раскрывающиеся таблицы.
- Тепловая карта: серые убыточные зоны, маркер текущего сценария,
  подсказки с экономикой каждой ячейки и счётчики исходов.
  Насыщенность — абсолютная разница EBITDAR; победителя выбирает модель.

## Что ещё требует работы команды
Рейтинг предварительный: полный набор полей режима case не предоставлен.
Наличие источников в данных не означает внешнюю проверку этих источников.
Пассажиропоток/частота Dev 1 и годовая экономика Dev 3 пока независимые модели:
спрос по отдельной паре не ограничивает загрузку в финансовой модели.
Экономика содержит сценарные субсидии и постоянные затраты. Прибыльность не
является доказанной. Прирост доли рассчитан без каннибализации существующей сети.
Флот оценён моделью Dev 3; ротации самолётов и волны стыковок не оптимизированы.
Кварталы Dev 1 не являются подтверждённым планом поставок/запуска.
