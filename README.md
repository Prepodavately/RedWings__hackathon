## Интегрированный интерфейс Dev 4

Корневой `app.py` подключён к общим `ScoringWeights` и `FinModelInput`.
Четыре вкладки: сравнение и сеть, города, сценарии, данные и план запуска.

Запуск из корня репозитория (WSL / Linux / macOS):

```bash
python -m pip install -r requirements.txt
USE_MOCKS=1 python -m streamlit run app.py
```

PowerShell:

```powershell
$env:USE_MOCKS="1"
python -m streamlit run app.py
```

Без переменной окружения также используется режим 1. `USE_MOCKS=0` переключает импорты на Dev 1–3. Если их функции возвращают None, показывается сообщение о незавершённом модуле; автоматической подмены заглушками нет.

**Текущие заглушки постоянные.** Ползунки передают значения в функции команды, но ответы mock_provider.py не зависят от аргументов. Карточки, карта и сценарии честно показывают ответы провайдера. Это не экономическая рекомендация. Файлы общих контрактов, заглушек и модулей Dev 1–3 не изменены.

### Интерфейсы
- `get_scored_cities(weights)` получает нормированные веса, возвращает весь список; для экономической модели выбираются города с `is_top3=True`.
- `evaluate_hypotheses(params, top_cities)` возвращает карточки и вывод. Сценарии base/conservative вызываются отдельно, тест загрузки также вызывает этот модуль.
- `get_network_routes(hypothesis, hub_iata)` получает выбор стратегии и код хаба; таблица отображается и скачивается без преобразования единиц.
- Для географической схемы реальных маршрутов добавьте `origin_lat`, `origin_lon`, `dest_lat`, `dest_lon`. Пока поля не согласованы в общем контракте. В демо только для KUF/GOJ/PEE используются приблизительные центры городов, явно подписанные.
- Файлы источников и реальные данные обрабатывает Dev 1. UI отображает все возвращённые поля таблицы, в том числе дополнительные `source` и `method`, и отмечает их отсутствие.

### Открытые вопросы команды
1. `weekly_freq_per_route` / `freq`: вылеты в одну сторону или обороты? UI передаёт число без удвоения.
2. `market_share_delta_pct`: проценты или процентные пункты? Пока отображается сырое значение с предупреждением.
3. `pax`: период и единица, пассажиры на участках или уникальные поездки?
4. В config/settings.yaml база Red Wings 4 465 000, в справке кейса 2 700 000 за 2025 г. Dev 3 должен проверить; интерфейс не меняет значение.
5. Заглушки содержат только 3 города и 2 маршрута, включая SVX в топ-3. Для нового хаба Москва/Екатеринбург не подходят. UI предупреждает и не разрешает выбрать эти действующие базы как новый хаб.
6. Дорожная карта в UI — шаблон для капитана, не рассчитанный план распределения самолётов.
