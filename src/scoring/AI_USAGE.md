Дополнительное указание: каждому клонировать репозиторий, установить
`requirements.txt` и перейти на именную ветку; для Dev 2 — `feat/city-scoring`.

`https://github.com/Prepodavately/RedWings__hackathon.git`.

## Что сделал ИИ

1. Сопоставил слайд, распределение ролей и код `main`; нашёл отдельную ветку
   `feat/data-parsers`, прочитал её схему, формулы и происхождение показателей.
2. Сохранил снимок commit `e364ac7d9ee8307d08bcb2bf64f670ad93658889` с хешами
   без добавления предполагаемых значений московских пересадок.
3. Реализовал Python-скоринг, проверку входных данных и метаданных, два явно
   различающихся режима, API совместимости, CLI и анализ чувствительности.
4. Подготовил notebook, документацию, тесты и предварительные выгрузки на
   имеющемся снимке. Проверил работу кода в виртуальном окружении по
   `requirements.txt` проекта; дополнительные зависимости notebook указаны отдельно.
5. Отметил: веса экспертные; туристический индекс является прокси;
   доля московских пересадок отсутствует; смешаны годы части исходных данных;
   достоверность первоисточников вне репозитория независимо не проверена.

Числа в тестах — синтетические и не используются в предварительном рейтинге.
