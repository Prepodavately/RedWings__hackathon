# Dev 4: интерфейс по расширенному ТЗ

Запуск из корня в PowerShell:
```powershell
$env:USE_MOCKS="1"
.\.venv\Scripts\python.exe -m streamlit run app.py
```
Для модулей команды используйте `USE_MOCKS="0"`.

Реализованы: диапазоны ползунков ТЗ, выбор KUF/GOJ/SVX, нормированные веса,
вердикт и сравнительные KPI с дельтами, Scattergeo-карта, выделение топ-3,
таблица доказательств, CSV, сравнение с геометрическим путём через Москву,
сетка 117 вызовов финансовой модели по тарифу и частоте, оба сценария.
Карта Plotly использует географическую подложку, для её загрузки нужен доступ к CDN Plotly.

Новые колонки Dev 1 адаптируются в provider_bridge.py:
origin_iata/dest_iata → origin/dest; lat_o/lon_o/lat_d/lon_d → origin_lat/origin_lon/dest_lat/dest_lon.
Старый формат также принимается. proof_source отображается без изменения.
Полный слой кандидатов получает координаты из load_rosstat_and_rosaviatsia()
(колонки iata, lat, lon). Нет координат — нет выдуманного положения на реальной карте.

Моки теперь динамические, поэтому старое описание постоянных моков в корневом README
относится к предыдущей версии. Все 12 городов имеют искусственные признаки;
координаты — приблизительные центры городов. Источники спроса НЕ имитируются.
Экономика демо воспроизводит формулы командного ТЗ с условными коэффициентами;
не является реализацией или проверкой модели Dev 3. Цвет тепловой карты берётся
из winner провайдера. В демо победитель выбран по EBITDAR; он может оказаться
одним на всей сетке. Искусственная граница переключения не рисуется.

Оставшиеся межмодульные вопросы:
- get_network_routes не принимает active_routes_count: UI показывает оба количества,
  не обрезает подтверждённую сеть произвольно. Hub из 12 городов даёт максимум 11 лучей.
- SVX доступен по новому ТЗ, но это расширение существующей базы, а не новый хаб.
- Формула расходов в ТЗ умножает число односторонних рейсов на стоимость,
  названную стоимостью парного плеча: Dev 3 должен устранить двусмысленность.
- Финансовые коэффициенты, субсидии и вывод о доле рынка требуют источников.
- Время через Москву не вычисляется без расписаний: геометрия не доказывает
  экономию 5–8 часов. Подложка показывает соединения, не реальные трассы.
- Карта показывает базовый тариф из ползунка, не маршрутный тариф после поправок модели.
- Дорожная карта остаётся шаблоном капитана.

Проверка: `python -m pytest tests/test_contracts.py tests/test_ui_integration.py -q`.
Изменения проверены AppTest на Streamlit 1.41.1 и Plotly 5.24.1;
визуальный просмотр в браузере отдельно не выполнялся.
